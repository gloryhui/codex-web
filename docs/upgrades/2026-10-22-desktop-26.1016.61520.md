## 迁移与新增兼容问题

修改前保留旧版已修复资源和新版未修改资源；对照 `CUSTOMIZATIONS.md` 迁移后，使用 `diff -u` 生成新静态 patch，没有手写 diff hunk。补丁覆盖 main、worker、preload、app-initial、app-primary 和 index.html 六个文件；app-shared 等继续使用动态补丁。

新版首次启动实际触发 `e.setOpenURLHandler is not a function`。对照上游 Session configure 链补齐 `setOpenURLHandler`、`setWebContentsActivationHandler` 注册入口；Web 的弹窗仍经 `BrowserGuest.setWindowOpenHandler`，标签激活由 renderer 管理，不模拟并不存在的原生 OS Session 事件。

第二个实际故障为账户 HTTP 请求出现 `Cannot read properties of undefined (reading 'split')`：新版用 `process.versions.chrome.split()` 构造 HTTP client hints。纯 Node 运行时在既有 Electron `41.2.0` 兼容上下文中补齐对应 Chromium `146.0.7680.179`，值通过本机 Electron `41.2.0` 的 `process.versions` 核实；存在原生值时不覆盖。
