## 拆包迁移

旧已修复提取保存在忽略目录，与新版未经修改的提取并存。七个静态文件的补丁由 `diff -u` 重新生成；完整 `prepare_asar` 成功运行，最后新增的目录入口适配再次逐文件 dry-run 通过。

新版把路由和 Statsig provider 从 app-initial 拆到 initialize-app-host-services，把侧栏操作移到 app-primary，把附件拷贝拆到 composer-content / composer-attachment-actions。新增 `scripts/extracted_startup.mjs`，对启动模块共同匹配、分别写回，保持模块作用域，匹配异常立即失败。模型预热在 app-initial 导出 hook，经 startup 显式导入，沿用实际 config/query key 与自定义提供方区分。

历史加载器的新签名把 scope getter 和 request 分开传入，已按新版实际 `lT/Y6t` 调用链迁移并发补丁；保留请求预算、条目顺序、分页及原生 progressive 路径。账号目录的新 try/catch 和身份检查保留，只替换真实目录读取。

新版本地项目入口依赖 Desktop 的原生创建弹窗。Web 的本地入口改为既有服务端目录选择器；原生 Desktop 和远程项目弹窗保持原实现。实际鼠标点击、键盘 Enter、输入服务器路径、目录读取和取消均通过。
